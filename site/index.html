WHAT IT DOES

A model you can inspect,
not a black box.

URL Sentry derives lightweight features—such as URL length, punctuation, hostname shape and whether the host is an IP address—then combines small decision trees into a score.

The model was evaluated on domains held out from training, so the test is less likely to reward remembering the same domain. That still does not tell us how it will perform on new, live threats.

A score is not a verdict.

This is a portfolio learning demo—not a browser warning, security product, or advice to open a link. A low score cannot prove a URL is safe; attackers change patterns and false positives happen. For a suspicious link, avoid signing in through it and visit the organization’s known website directly.
